# Internship Finder Dashboard

##  Overview

The **Internship Finder Dashboard** is a responsive frontend web application designed to help students discover and explore internship opportunities in an organized and user-friendly interface.

The dashboard allows users to search for internships, filter opportunities based on different criteria, view internship details, and save interesting opportunities for later.

This project is developed using **HTML, CSS, and JavaScript** and is suitable as a college mini project and a frontend portfolio project.

---

##  Objectives

* Help students find internship opportunities easily.
* Provide a simple and organized internship-search interface.
* Allow users to search and filter internships.
* Provide important internship information in a single dashboard.
* Demonstrate frontend web development skills.

---

##  Features

###  Internship Search

Search internships using:

* Internship title
* Company name
* Skills
* Keywords

###  Internship Filtering

Users can filter internships based on:

* Location
* Work mode
* Internship category
* Duration
* Stipend

###  Internship Cards

Each internship card displays information such as:

* Internship title
* Company name
* Location
* Work mode
* Duration
* Stipend
* Required skills
* Application link

###  Save Internships

Users can save interesting internship opportunities and access them later from the saved section.

###  Dashboard Statistics

The dashboard provides useful statistics such as:

* Total internships
* Available internships
* Saved internships
* Internship categories

###  Responsive Design

The application is designed to work across:

* Desktop
* Laptop
* Tablet
* Mobile devices

##  How It Works

1. Open the Internship Finder Dashboard.
2. Browse the available internship opportunities.
3. Use the search bar to find specific internships.
4. Apply filters according to your requirements.
5. View internship details.
6. Save internships that you are interested in.
7. Click the **Apply** button to proceed to the application page.
